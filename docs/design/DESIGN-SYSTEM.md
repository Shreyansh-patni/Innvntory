# DESIGN SYSTEM

**Primary Visual Reference:** Aoutive AI (`docs/references/aoutive-ai/`)
**Secondary Design Principle Reference:** Cursor Design Analysis (`docs/references/cursor/`)

## Design Knowledge Model
- **Aoutive AI:** The most important visual evidence. Study page composition, spacing, whitespace, navigation, typography, card construction, borders, image treatment, grid structure, section rhythm, CTA patterns, forms, FAQ, footer, responsive behavior, visual density, transitions, interaction patterns. *Do not copy Aoutive branding, wording, product claims, or logo.*
- **Cursor:** Use for design principles such as restrained visual language, strong typography, refined spacing, minimal visual noise, clean hierarchy, subtle borders/hairlines, intentional whitespace, focused interaction design. *Do not import Cursor colors or branding.*

## Design Evidence Rule
For visual decisions, do not say "This is modern, therefore use X." Instead:
1. Inspect reference
2. Identify observable pattern
3. Document pattern
4. Adapt pattern to Innvntory
5. Mark final value TBD when necessary.

## Typography & Color Policy
The project has design inspiration but does NOT yet have permission to blindly copy external brand tokens. Establish Innvntory-specific tokens only when justified. Unapproved tokens remain TBD.
